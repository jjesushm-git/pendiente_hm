# Mis Tareas — Versión 10.0.4.2

Base: Versión 10.0.4 estable.

Cambio principal:
- Al tocar directamente el emoticono de una tarea, solo se edita el emoticono.
- No se abre el formulario completo de la tarea.
- El selector de emoticonos se abre sobre la pantalla actual.
- Al elegir un nuevo emoticono, el cambio se guarda inmediatamente.
- Después aparece un modal de confirmación "Emoticono actualizado".
- El aviso se puede cerrar con X o tocando fuera del modal.
- Al cerrar, permaneces en la misma pantalla/vista donde estabas.
- La edición normal de la tarea sigue permitiendo cambiar el emoticono desde el formulario.
