- Títulos principales con tipografía serif clásica y cuerpo de texto sans-serif.
- Paneles, tarjetas, calendario, semana, tablero, gastos, libros, ajustes y modales en estilo marfil con bordes dorados.

- Navegación inferior clara con botón Agregar verde/dorado.
- Formularios, selects, switches, chips y confirmaciones adaptados al mismo lenguaje visual.
- Los temas Noche violeta, Azul océano y Grafito no se modifican.
- No se cambia la lógica funcional de tareas, gastos, libros, papelera, comentarios o exportaciones.
- No se cambia la estrategia del Service Worker respecto a la versión base.
