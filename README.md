# Mis Tareas — Versión 9

Cambios principales:
- La fecha de vencimiento ya no es obligatoria.
- Las tareas sin vencimiento permanecen pendientes hasta completarse manualmente.
- Las tareas sin vencimiento no generan recordatorios de vencimiento.
- Gantt fue reemplazado por un Tablero de actividades.
- Tablero con columnas: Pendientes, En proceso, En espera y Completadas.
- Las tareas pueden moverse entre columnas desde un selector.
- Se conservan Calendario, Día, Semana, Papelera, Editar y Eliminar.
- Papelera conserva tareas durante 24 horas.
- Compatible con las tareas guardadas en versiones anteriores.
- Sigue usando almacenamiento local; Supabase se integrará posteriormente.
