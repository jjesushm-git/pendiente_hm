# Mis Tareas — Versión 11.7.8.2

Base: Versión 11.7.8.1 ESTABLE.

## Calendario
Se aumentó únicamente la legibilidad dentro de las celdas:

- Número del día más grande.
- Emoticono de una sola tarea más grande.
- Número del contador de tareas 2–4 / 5+ ligeramente más grande.
- El contador amarillo/rojo conserva su tamaño compacto.

## Importante
No se modificó:
- ancho de las celdas,
- altura de las celdas,
- número de filas del calendario,
- `min-height` de los días,
- `grid-auto-rows`,
- espaciado general del calendario.

Por eso el calendario mantiene exactamente el mismo tamaño de la versión anterior; solo aumenta el contenido visual dentro de cada día.

## Validación
- JavaScript sin errores.
- CSS sin errores.
- Sin IDs HTML duplicados.
- Sin referencias JavaScript a elementos inexistentes.
- Calendario, Día, Semana, Tablero, Libros, Movimientos y periodos financieros se conservan.
