# Mis Tareas — Versión 11.7.8.1

Base: Versión 11.7.8 ESTABLE.

## Ajuste de colores de texto
Se corrigieron textos que se veían negros o demasiado oscuros dentro del tema Esmeralda/Dorado.

Se creó una jerarquía visual más suave:
- Títulos principales: verde esmeralda profundo.
- Encabezados secundarios: verde medio sobrio.
- Texto normal: verde grisáceo oscuro.
- Metadatos: verde grisáceo medio.
- Leyendas pequeñas: gris verdoso suave.
- Acciones neutrales: verde esmeralda.
- Acentos financieros: dorado discreto.
- Ingresos: verde.
- Gastos / acciones destructivas: rojo apagado.

Se conservan en crema/blanco los títulos que están sobre encabezados verdes oscuros.

También se corrigió el color del número sobre indicadores amarillos para evitar gris casi negro.

No se modificó ninguna lógica de tareas, libros, recurrencias, calendario, gastos/ingresos, Bitácora ni periodos financieros.
